# FT-563 · Три в ряд

## Контрольная точка 1 — 15.10.2026

Ветка `codex/ft-563-match3`. Разработка третьей игры по подтверждённому плану.
Готовы: чистая модель и очередь сессии, два изображения с точными промптами.
Проверка `node --test scripts/test-match-model.mjs`: 9 тестов прошли,
включая 2000 стартовых полей и 150 полных партий.

Следующее: MatchGame.jsx и match-game.css, локальный preview, меню/отдых,
численная настройка цели, browser QA, визуальное ревью.

## Правила

Поле 6×6, шесть типов предметов, 12 ходов. Совпадение из трёх исчезает;
четыре создают заряд линии, пять — цветной заряд, Т/Г — взрыв 3×3.
Цветной заряд меняется с любым предметом и убирает его тип. Два специальных
предмета можно соединить без тройки. Каскады умножают очки (до ×4).
Недопустимый обмен возвращается без расхода хода. Тупик перемешивается
бесплатно, сохраняя специальные фигуры. Все параметры в match-model.js.

Первоначальная цель — 900 очков; ещё требует численной проверки и плейтеста.
Численная проходимость не подтверждает интересность игры человеку.

## Устройство

- `match-model.js`: чистые правила, seeded random, неизменяемые входы,
  последовательность кадров хода.
- `match-session.js`: очередь кадров, остаток задержки при паузе,
  единственный владелец управления, подписка на снимки.
- `MatchSession.jsx`: общая партия в памяти текущего кабинета.
- `assets/match-pieces.png`: настоящий alpha, 3 столбца × 2 строки.
  По порядку: гантель, гиря, диск, яблоко, бананы, брокколи.
- `assets/match-gym.png`: фон. Оба ассета созданы imagegen;
  исходные запросы — в одноимённых `.prompt.txt`.

## Границы выпуска

План: только существующий тестовый доступ me.plankGameEnabled.
Боевой API и сохранение результатов на сервер не нужны. Web deploy не
запрошен; push рабочей ветки не публикует приложение. iPhone получает
общий web-код через prepare-ios.sh → www-app со следующей явно запрошенной
сборкой. Android получает его после отдельной веб-выкладки.
