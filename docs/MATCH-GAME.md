# FT-563 · Три в ряд

## Полноэкранная версия 19.10.2026

Ветка `claude/games-match`. Игра больше не карточка шириной 460 px со
скруглением, а полноэкранная сцена, как «На самокате до зала». Правила,
модель, сессия, звук и баланс не менялись — только разметка `MatchGame.jsx`
и стили `match-game.css`.

- Рисунок зала — на весь экран, игра занимает 100 % высоты оболочки
  (`GameShell` из меню, `.rest-screen--game` на отдыхе) и не прокручивается.
  Вне оболочки — `min-height: 100svh`.
- Белого тулбара «Три в ряд» нет. Сверху поверх фона: слева «Закрыть игру»
  (на отдыхе «К отдыху»), справа звук и «Пауза» — кремовые кнопки 46 px
  (44 px на экранах ниже 640 px) с тенью, отступ
  `calc(10px + env(safe-area-inset-top))`. На отдыхе в той же строке —
  плашка таймера отдыха (`role="timer"`).
- Заголовок «В форме!» и название главы из партии убраны: глава видна во
  вступлении, паузе и итоге. Над полем — компактный HUD (ходы, очки, шкала,
  звёзды) и квест главы.
- Поле — самый большой квадрат в оставшемся месте: `.match-stage`
  (`flex: 1; min-height: 0; container-type: size`) и рамка
  `width: min(100cqw, 100cqh)`, без container queries — `width: 100%` с
  ограничением по высоте. Клетка (замер Chromium, было → стало):
  390×844 — 37,8 → 41,3 px; 360×740 — 36,2 → 38,0 px; 320×568 — 31,8 →
  32,7 px; 1280×800 — 45,5 → 54,4 px. На телефоне ширина — предел: поле
  почти от края до края (4 px), больше без потери рамки не выжать. Раньше
  на 360×740, 320×568 и 1280×800 страница прокручивалась — теперь нет.
- Снизу — лента сообщений тренера, «Подсказка» и «Как играть» с
  safe-area снизу.
- Панели (вступление главы, правила, пауза, итог, ошибка рисунков) — на весь
  экран поверх сцены; на телефоне лист снизу, от 700 px — по центру.
- Широкий экран (от 700 px): колонка до 640 px по центру, по бокам зал.
- `useGameChrome(rootRef)`: в нативной оболочке скрыта строка состояния,
  при выходе снимается полноэкранный режим.
- Вибрация (`buzz` из `game-feel.js`, только у экрана-владельца партии и не
  на паузе): `tap` — выбор и обмен, `good` — совпадение, `great` — каскад ×2+,
  срабатывание бонуса и победа, `bad` — неверный обмен. В паузе — галочка
  «Вибрация» (`vibrationOn/setVibration`, хранится на устройстве). На iPhone
  Vibration API нет — там молчит.
- При «уменьшении движения» поле при повороте не «доезжает» анимацией до
  нового размера (общий `transition-duration` касался и ширины рамки).
- Превью `/match-preview.html` и тестовая фикстура обёрнуты в
  `.game-shell.game-shell--match`, как в приложении.

## Доработка: сюжет, поле 9×9 и игровой отклик — 16.10.2026

Основание: запись владельца `ScreenRecording_10-16-2026 01-41-40_1.mp4`.
В записи обмен, очистка и падение почти неразличимы; счёт меняется быстрее,
чем глаз успевает связать его с фигурами. Цель доработки — читаемый цикл
«обмен → совпадение → взрыв/бонус → падение → каскад → награда» без потери
приоритета таймера отдыха.

Вторая запись владельца `ScreenRecording_10-16-2026 01-46-20_1.mov` —
референс крупного игрового поля с ящиками и явной целью над ним. По просьбе
владельца поле расширено до 9×9, добавлены группы закрытых клеток.
Закрытую клетку нельзя поменять; совпадение в ней или рядом раскрывает её.
Для победы в главе нужны очки, сюжетные фигуры и 6 раскрытых ящиков.

Три главы одной короткой истории с тренером: открыть зал и собрать инвентарь,
дать команде энергию, завершить рекордный сет. Каждая глава имеет 20 ходов
и цель по очкам, но получает отдельную коллекционную цель по одному виду фигур.
Собранные фигуры считаются при очистке поля, в том числе бонусами; победа
требует и очков, и сюжетной цели. Входная сцена сообщает причину задания,
игровой HUD показывает его прогресс, победа открывает следующую главу,
поражение предлагает повторить ту же главу. После третьей главы — эпилог
и возможность начать историю снова. Пауза, выход, смена сцены и reload
сохраняют прежние правила жизни партии.

Проверки: численно подобрать цели на 1800 партиях по трём главам; тесты подсчёта фигур,
победы и последовательности глав; Chromium/WebKit для анимации, паузы
посреди каскада, узкого экрана и `prefers-reduced-motion`; снимки из
настоящей игровой сцены. Новых библиотек нет. Физический плейтест
владельца нужен для оценки ощущения от анимации.

Контроль баланса 16.10.2026: по 300 партий на главу и стратегию.
Доля побед случайной/локально жадной стратегии: глава 1 — 82/73%,

## Правила

Поле 9×9, шесть типов предметов, 20 ходов. Совпадение из трёх исчезает;
четыре создают заряд линии, пять — цветной заряд, Т/Г — взрыв 3×3.
Цветной заряд меняется с любым предметом и убирает его тип. Два специальных
предмета можно соединить без тройки. Каскады умножают очки (до ×4).
Недопустимый обмен возвращается без расхода хода. Восемь закрытых ящиков
на поле открываются совпадениями рядом; для победы нужно открыть шесть.
Тупик перемешивается бесплатно, сохраняя специальные фигуры.
Все параметры в match-model.js и match-story.js.

Цели глав — 2000/2250/2500 очков и 12/14/16 сюжетных фигур.
Интересность оценит
человек в коротком отдыхе.

## Устройство

- `match-model.js`: чистые правила, seeded random, неизменяемые входы,
  последовательность кадров хода.
- `match-session.js`: очередь кадров, остаток задержки при паузе,
  единственный владелец управления, подписка на снимки.
- `MatchSession.jsx`: общая партия в памяти текущего кабинета.
- `assets/match-pieces.png`: настоящий alpha, 3 столбца × 2 строки.
  По порядку: гантель, гиря, диск, яблоко, бананы, брокколи.
- `assets/match-gym.png`: фон. Оба ассета созданы imagegen;
  исходные запросы — в одноимённых `.prompt.txt`.

## Границы выпуска

Доступ — только существующий `me.plankGameEnabled`.
Боевой API и сохранение результатов на сервер не нужны. Доработка выложена
в веб-версии 3.13. iPhone получает общий web-код через `prepare-ios.sh` →
`www-app` со следующей явно запрошенной сборкой. Android-приложение также
содержит вшитые экраны и получит их только с новой APK-сборкой.
