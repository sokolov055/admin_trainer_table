# FT-563 · Три в ряд

## Доработка: сюжет и игровой отклик — 16.10.2026

Основание: запись владельца `ScreenRecording_10-16-2026 01-41-40_1.mp4`.
В записи обмен, очистка и падение почти неразличимы; счёт меняется быстрее,
чем глаз успевает связать его с фигурами. Цель доработки — читаемый цикл
«обмен → совпадение → взрыв/бонус → падение → каскад → награда» без потери
приоритета таймера отдыха.

Три главы одной короткой истории с тренером: открыть зал и собрать инвентарь,
дать команде энергию, завершить рекордный сет. Каждая глава сохраняет 12 ходов
и цель по очкам, но получает отдельную коллекционную цель по одному виду фигур.
Собранные фигуры считаются при очистке поля, в том числе бонусами; победа
требует и очков, и сюжетной цели. Входная сцена сообщает причину задания,
игровой HUD показывает его прогресс, победа открывает следующую главу,
поражение предлагает повторить ту же главу. После третьей главы — эпилог
и возможность начать историю снова. Пауза, выход, смена сцены и reload
сохраняют прежние правила жизни партии.

Проверки: численно подобрать цели на 2000 партиях; тесты подсчёта фигур,
победы и последовательности глав; Chromium/WebKit для анимации, паузы
посреди каскада, узкого экрана и `prefers-reduced-motion`; снимки из
настоящей игровой сцены. Новых библиотек нет. Физический плейтест
владельца нужен для оценки ощущения от анимации.

## Правила

Поле 6×6, шесть типов предметов, 12 ходов. Совпадение из трёх исчезает;
четыре создают заряд линии, пять — цветной заряд, Т/Г — взрыв 3×3.
Цветной заряд меняется с любым предметом и убирает его тип. Два специальных
предмета можно соединить без тройки. Каскады умножают очки (до ×4).
Недопустимый обмен возвращается без расхода хода. Тупик перемешивается
бесплатно, сохраняя специальные фигуры. Все параметры в match-model.js.

Цель первого уровня — 900 очков, численно проверена; интересность оценит
человек в коротком отдыхе.

## Устройство

- `match-model.js`: чистые правила, seeded random, неизменяемые входы,
  последовательность кадров хода.
- `match-session.js`: очередь кадров, остаток задержки при паузе,
  единственный владелец управления, подписка на снимки.
- `MatchSession.jsx`: общая партия в памяти текущего кабинета.
- `assets/match-pieces.png`: настоящий alpha, 3 столбца × 2 строки.
  По порядку: гантель, гиря, диск, яблоко, бананы, брокколи.
- `assets/match-gym.png`: фон. Оба ассета созданы imagegen;
  исходные запросы — в одноимённых `.prompt.txt`.
