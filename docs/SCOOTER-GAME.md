# FT-563 · На самокате до зала

Версия v3 (17.10.2026, Web 3.18) — бесконечная аркада с видом сверху.
Игрок едет по мощёной аллее между бегунами, бабушками, качками после дня ног,
доставщиками и ремонтом. Каждые 500 м после первого перехода на 450 м аллея
пересекает дорогу. Машины идут поперёк, зебра ведёт пешеходов вдоль аллеи.
Машины уступают НПС, уже въехавший автомобиль сначала освобождает переход,
пешеход ждёт у бордюра. Быстрый НПС сохраняет дистанцию за медленным.

Финиша и прежнего таймера нет. Любое столкновение завершает заезд.
Три сложности: «Разминка», «Час пик», «Предел». Скорость растёт с дистанцией,
плотность препятствий тоже; нитро добавляет 45% на 3,2 секунды.
Предтрен даёт до двух зарядов, вода — только очки.
Рейтинг сравнивает метры отдельно по сложности, время показывается справочно;
при равных метрах выше более ранний рекорд.

## Рисунок и управление

Canvas занимает всю высоту 100dvh; в меню приложения самокат монтируется порталом
в body. Имя клиента, шапка приложения, название игры и нижняя настройка
не занимают игровое поле. Название, сложность, управление, рейтинг и сворачивание
находятся в меню. На desktop поле ограничено 640 px. Системная строка состояния
скрывается существующим StatusBar; при выходе восстанавливается.

Персонажи и транспорт — локальные PNG-атласы, предварительно нарисованные в 3D
для вертикальной камеры. Это Canvas, а не трёхмерный движок. Самокатчик уменьшен
примерно на четверть относительно предыдущего рисунка. Все фигуры сортируются
по глубине вместе с игроком; границы столкновений учитывают видимый размер.
Контакт колёс, короткая тень, след по плитке, небольшая пыль, наклон в повороте
и микровибрация от пройденных стыков связывают игрока с покрытием.
При reduced motion декоративные эффекты выключены. DPR до 3, качественное
уменьшение растров. Промпты сохранены рядом с ассетами и в метаданных PNG.
Три игры получили собственные предметные 3D-иконки.

Кнопки, клавиатура и свайп доступны без датчика. Наклон телефона включается
в меню и калибруется по текущему положению; при отказе остаются кнопки.
Текстовые реплики НПС появляются при близком объезде; озвучка добровольная,
только установленным локальным русским голосом, без сетевого синтеза.

## Сессия, доступ и рейтинг

Входы из меню и отдыха используют прежний PlankAccess:
клиентская роль и me.plankGameEnabled === true из clients.is_test.
Поездка общая, хранится в памяти до перезагрузки или смены кабинета.
Закрытие, фон и конец отдыха ставят игру на паузу. Одновременно смонтированные
сцены имеют одного владельца часов и управления; размонтирование снимает датчик,
обработчики, RAF и ResizeObserver.

Рейтинг включается отдельным согласием версии 2026-10-17. Без него можно играть
локально. Вместо имени сервер создаёт случайный псевдоним. Таблица закрыта
авторизацией тестовых клиентов, отдаёт только псевдоним, метры, секунды и «я».
Отзыв удаляет игрока, старты и рекорды; экспорт и удаление аккаунта включают
игровые данные. Тексты: public/game-consent.html, политика редакции 7; архив 6
сохранён. Юридическая карта — docs/legal/2026-10-17-scooter-ranking.md
в основном репозитории.

API только POST: scooter.board/join/leave/start/finish. Сервер выдаёт seed,
сложность и версию правил, затем воспроизводит журнал полос/нитро по 60 Гц
и сам считает дистанцию. Присланные очки/дистанция не принимаются.
Сохраняется лучший результат каждой сложности. Журнал в базе не хранится;
технические старты очищаются через сутки при обращении к игровому API.
Повтор отправки результата идемпотентен; поздний ответ прошлого заезда
не стирает новый. Ошибка сети видна пользователю, доступна повторная отправка.
Проверка целостности не заявляется как защита от ботов.

Клиентская и серверная scooter-model.js должны совпадать побайтно.
RULES_VERSION = 2; при следующем изменении опубликованных правил поднять
версию с обеих сторон, чтобы незавершённые попытки не проверялись чужой моделью.

## Платформы и проверки

iOS и Android используют общий код, встроенный в www-app через prepare-ios.sh
и build-apk.sh. Новых нативных зависимостей нет; код готов к следующим сборкам.
Текущие iOS build 20 и Android APK 8 не скачивают новую игру с сайта.
Пользовательские мобильные сборки в этой задаче не выпускаются.

Проверки: npm run test:scooter — 21 (13 модели, 3 сессии, 5 browser);
сервер test/scooter.test.js — 7. Общие тесты веба — 363, сервера — 748;
production build. Полный E2E включает меню/доступ, запуск из отдыха,
возврат и приоритет таймера. WebKit отдельно проверен на старте, паузе,
наклоне и размонтировании.

Численный водитель с задержкой реакции 0,32 сек на 100 seed каждой сложности:
медианы выживания 22 / 14 / 5 секунд. Он не предсказывает поперечный трафик,
поэтому это сравнительная нагрузка, не человеческая оценка сложности.
Человеческий плейтест, физический датчик и производительность на телефоне
ещё требуют проверки.

Ручной QA: тестовый клиент → Меню → «На самокате до зала» → «В путь»;
объехать НПС, собрать предтрен, включить нитро, столкнуться и повторить.
В рейтинге дать согласие, закончить заезд, проверить рекорд, затем отозвать.
На отдыхе дождаться сигнала и продолжить ту же поездку на следующем отдыхе.
