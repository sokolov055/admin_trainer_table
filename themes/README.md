# Темы оформления файлом

Исходники тем, которые загружаются в «Управление → Вид» (с 22.10.2026), — по
папке на тему: `<id>/theme.mjs`. В сборку приложения не входят: файл темы
собирает скилл `app-theme` основного репозитория
(`.claude/skills/app-theme/scripts/export-theme.mjs`), владелец загружает его в
панели. Здесь они — чтобы тему можно было поправить и пересобрать.
