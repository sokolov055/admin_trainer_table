# Fit Track
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Клиент персонального тренера и тренер, проводящие занятие с телефоном в зале.

## Product Purpose
Программа, запись подходов и история результатов доступны внутри приложения.

## Capabilities and Constraints
Подтверждено пользователем: обе роли могут менять упражнения и подходы конкретного занятия; исходная программа сохраняется для следующих тренировок.
Таблицы — источник данных; запись выполняет Apps Script. Расчёт оплат остаётся по календарю.
Русский интерфейс, существующие компоненты и SVG-иконки. Черновик на устройстве должен сохраняться при прерывании занятия, а статус облачного сохранения должен быть явным.
Тренер может отозвать все входы клиента, не удаляя его данные, и отдельно отвязать Telegram для полного повторного подключения по персональной ссылке.
Тренер создаёт отзываемые многоразовые и одноразовые реферальные ссылки. Новый клиент сам создаёт кабинет через подтверждение Telegram; готовая email-ветка показывается только когда сервер явно включает её feature flag.
Из бокового меню тренер может открыть настоящий клиентский интерфейс для выбранного клиента и вернуться обратно, не меняя свою серверную роль и права.
