# Fit Track
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Клиент персонального тренера и тренер, проводящие занятие с телефоном в зале.

## Product Purpose
Программа, запись подходов и история результатов доступны внутри приложения.

## Capabilities and Constraints
Подтверждено пользователем: обе роли могут менять упражнения и подходы конкретного занятия; исходная программа сохраняется для следующих тренировок.
Источник данных — база сервера; Google Таблицы, Apps Script и Telegram выведены 27.09.2026. Баланс занятий считается из расписания и оплат на сервере. Полные требования к продукту — `../docs/PRODUCT.md` основного репозитория.
Русский интерфейс, существующие компоненты и SVG-иконки. Черновик на устройстве должен сохраняться при прерывании занятия, а статус облачного сохранения должен быть явным.
Тренер может отозвать все входы клиента, не удаляя его данные.
Тренер создаёт отзываемые многоразовые и одноразовые реферальные ссылки. Новый клиент сам создаёт кабинет по почте и привязывается к тренеру с согласия.
Из бокового меню тренер может открыть настоящий клиентский интерфейс для выбранного клиента и вернуться обратно, не меняя серверную роль. Предпросмотр получает клиентскую видимость: скрытые листы и тренерские действия в нём недоступны.
При открытии панели тренера календарь пересчитывается в фоне: интерфейс сразу показывает зеркало, не допускает параллельных дублей операции и перечитывает клиентов после завершения.

FT-551: продукты с этикеток имеют бренд, штрихкод цифрами и вид веса;
справочные продукты показывают источник, пользовательские — статус проверки.
Владелец проверяет каталог в «Библиотека → Продукты». Учебная вкладка питания
называется «Подсказки», содержит только короткие материалы; расчёт нормы,
темп и анкета открываются отдельно в «Норма и анкета», подбор — в «План меню».

FT-551: сканер продукта читает фото штрихкода или этикетки локально; на сервер
попадают только проверенные пользователем поля. Результат OCR — черновик,
значения на 100 мл/порцию автоматически в 100 г не переносятся.


FT-819, этап 1 (23.11.2026): «Библиотека → Тренажёры» использует
компактный список в стиле Программ: Мои/Общие, поиск по названию, модели,
бренду и связанному упражнению, фильтры по типу/бренду/мышцам/отсутствию
связей. Состояние списка сохраняется при возврате из карточки. При поиске Мои/Общие
остаются видимыми; пустая область явно отличается от отсутствия совпадений. Стили
`machines-lib.css` изолированы классами `mlib-*`; Программы не меняются.
API не отдаёт даты оборудования: исходный порядок обозначен «В каталоге»;
«Частые» — по числу связанных упражнений. Карточка и редактор остаются
следующими этапами FT-819. iOS/Android получают общий код со следующими
отдельно запрошенными сборками.

FT-819: обложка тренажёра в списке показывает первое фото целиком
(`photos[0]`, совместимость с `photo` сохранена); значок используется,
когда фото нет либо оно не загрузилось. Остальная фотолента не меняется.

FT-819, этап 2: карточка тренажёра имеет обложку с четырьмя фактами,
фотографии целиком с сохранёнными номерами шагов, раскрытые блоки настройки
и связанных упражнений. Привязка — в отдельном листе, изменение/удаление —
в «…», удаление использует общий возврат. Общий объект чужого тренера
не удаляется; правка и привязка сохраняют прежний API личных версий.
Редактор формы остаётся следующим этапом, Программы не меняются.
