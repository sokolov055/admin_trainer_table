# Наборы для игр файлом

Исходники наборов, которые загружаются в «Управление → Игры» (с 22.10.2026):
вопросы «Тренера в планке» и уровни «Блинов», по папке на набор —
`<id>/pack.mjs`. В сборку не входят: файл собирает скилл `game-pack`
основного репозитория (`.claude/skills/game-pack/scripts/export-pack.mjs`),
владелец загружает его в панели.
